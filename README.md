# 算力天梯

[打开网站](https://casazaft.github.io/chiprank_pub/)

跨厂商 GPU、统一内存芯片与 AI 加速卡的规格比较工具，支持多指标排序、最多 5 款产品并排比较，以及当前筛选结果导出。

此仓库仅保存公开网站的 HTML、CSS、展示用 JavaScript、整理后的数据快照，以及 GitHub Pages 部署配置。网站数据由维护方更新；此仓库不执行数据采集。

数据包含硬件规格、发布日期、发布售价、带日期的价格样本汇总，以及数值来源链接。算力以“官 / 推 / 测 / 参”分别标记官方理论、推算、实测和第三方规格；测试条件、来源日期与测试日期可在产品详情查看。矩阵只展示稠密值与已知稀疏倍率。未知值留空。

价格统计仅代表特定日期、地区与有限样本，不能视为全站均价或实际成交价。网站发布时间不等于数据重新核验日期。

此仓库不包含后端、采集或解析程序、第三方页面副本、原始采集记录、商品标题及店铺明细、数据库、登录信息或开发历史。引用链接用于标明出处；第三方名称及商标归各自权利人所有。

如发现数值错误或内容权利问题，请通过本仓库 Issues 提供具体记录和依据，便于核对、更正或移除。
