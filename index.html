01 / COVERAGE

跨厂商，多种内存方案

NVIDIA 覆盖 Ampere、Ada、Hopper、Blackwell；AMD 覆盖同期 RDNA 与 CDNA 产品；Intel 覆盖 Arc、Arc Pro 与数据中心 GPU。同时收录中国特供型号、Apple / NVIDIA / AMD 统一内存 SoC，以及华为、寒武纪、摩尔线程等国产加速产品。消费级拆为台式机和 Mobile，Mobile 包括笔记本的独立 GPU、集成 GPU 和统一内存芯片。跨平台芯片可同时筛入两类，列表和总数去重。移动型号单独标记。数据库是可扩展的规格快照，不能保证涵盖所有 OEM、地区和新发布变体。

02 / PROVENANCE

每个数值可追溯

规格参考厂商文档、TechPowerUp 等第三方资料及公开研究。数值保留来源链接、核验日期和必要的口径说明；官方理论、推算和实测分别标记。此站展示整理后的规格事实与原创比较说明。

03 / COMPARABILITY

把口径放在数值旁边

通用 FP16 / FP32 / FP64 与矩阵算力分开。矩阵统一按稠密算力排名，并标注已核验的稀疏倍率；不重复列出稀疏算力。INT4 / INT8 使用 TOPS，其余使用 TFLOPS。稀疏倍率要求特定数据结构，不能默认视为 2 倍。不同 GPU 的累加精度、时钟和指令路径可能不同，比较前请查看详情。

04 / UNITS

容量、带宽与理论峰值

独立显存按产品标称 GB 保存；统一内存注明固定配置或最高支持容量，最高值以 ≤ 标记，CPU/GPU 共享，实际可供 GPU 分配容量受系统和配置限制。NPU 或整机 AI TOPS 不作为 GPU 通用 / 矩阵算力。带宽统一为十进制 GB/s（1 TB/s = 1000 GB/s）。算力数值以下标注明口径，优先官方理论、其次推算和已有第三方规格，再用实测补缺。相同口径按测试日期（未知时按来源日期）选最新记录，不自动取最大值。按显示值排序；不同口径或测试条件不代表严格横向性能对比，所有记录均可在详情查看。多芯片产品须注意单芯片与整卡口径。未公开、不支持或未完成核验的指标留空，默认不参与排名。移动 GPU 的功耗配置会影响表现。
